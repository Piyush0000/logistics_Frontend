One thing to decide with these: the assistant

D and E show an "Ask Evoc" assistant. The backend has no AI service today, so there are two honest ways to do it.

1

Smart insights now, chat later

Cards that point out things from your own data ("14 NDRs need an answer", "Ekart is slower to Pune this week"). No AI service needed; works today. The chat box comes when the backend adds AI.

2

Real chat assistant

A Claude-powered assistant that answers questions about your shipments. Needs an API key and a server route in the frontend, plus care about which data it can see.

3

No assistant

Use that space for another chart or the "Needs you today" task list.
